# CRUD-LABORATORIO

Proyecto académico para construir un CRUD de personas utilizando PHP, MySQL, HTML y CSS, siguiendo como guía el documento del laboratorio.

## Estructura prevista

```text
CRUD-LABORATORIO/
├── bd/
│   └── .gitkeep
├── css/
│   └── .gitkeep
├── conexion.php
├── delete.php
├── index.php
├── insert.php
├── update.php
└── README.md
```

## Responsabilidad de los archivos

- **bd/**: scripts SQL para crear la base de datos y sus tablas.
- **css/**: hojas de estilo de la interfaz.
- **conexion.php**: conexión PHP con MySQL mediante PDO.
- **index.php**: listado y búsqueda de personas.
- **insert.php**: formulario y proceso de registro.
- **update.php**: consulta y modificación de registros.
- **delete.php**: eliminación de registros.

## Entorno de ejecución

El proyecto se ejecutará localmente con XAMPP. La carpeta del repositorio debe ubicarse dentro de:

`C:\xampp\htdocs\CRUD-LABORATORIO`

Luego se podrá abrir desde:

`http://localhost/CRUD-LABORATORIO/`

## Estado

Estructura inicial preparada. La implementación se realizará progresivamente durante el laboratorio. No se incluyen credenciales ni datos personales reales.
